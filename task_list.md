# BambooHR Interactive Features & Button Checklist - Limitlessli HR

This document lists every button, modal, dropdown, sub-tab, and action across the entire Limitlessli BambooHR portal, along with its implementation state.

---

## 1. Top Header & Navigation
- [x] **Limitlessli Swirling Logo**: Navigates to `Home` dashboard.
- [x] **Global Search Input**: Interactive search filter across employees, files, and jobs.
- [x] **Notification Bell (Badge 1)**: Interactive dropdown panel showing recent alerts (ID Past Due, Announcements, Approvals).
- [x] **Help Icon (?)**: Opens BambooHR Support & Knowledge Base drawer.
- [x] **Settings Gear Icon**: Opens Admin Settings modal (Company Profile, User Roles, Integrations, Custom Fields).
- [x] **+ Ask Button**: Opens AI HR Assistant drawer ("Ask Limitlessli AI").

---

## 2. Home Dashboard Actions & Widgets
- [x] **+ New... Dropdown**: Quick action menu (Request Time Off, Record Training, New Employee, New Job, Upload File).
- [x] **Edit Button**: Dashboard layout customization mode (toggle/reorder widgets).
- [x] **Request Time Off Button**: Multi-type time off request modal with start/end date calculation.
- [x] **Calculator Button**: Time off accrual projections calculator modal.
- [x] **Clair On-Demand Pay**: Opens Clair payroll details drawer & setup wizard.
- [x] **Headcount Chart**: Interactive monthly breakdown modal (Hires vs Terminations).
- [x] **What's Happening Activity Feed**: Clickable feed items (View ID task, view announcements, celebrate new joiners).
- [x] **Live Learning Lab Promo**: Close button + `Sign Me Up!` registration modal.

---

## 3. My Info Profile Pages & Sub-Tabs
- [x] **Request a Change Dropdown**: Opens profile change request form (Name, Address, Direct Deposit, Tax info).
- [x] **... Profile Actions**: Print profile, Export PDF, Change Avatar photo modal.
- [x] **Personal Sub-Tab**: Full personal info (Contact details, Address, Emergency contacts, SSN/ID, DOB).
- [x] **Job Sub-Tab**: Job history, Department, Employment status, Pay rate, Division, Manager assignment.
- [x] **Emergency Sub-Tab**: Emergency contacts list with Add/Edit/Delete actions.
- [x] **Time Off Sub-Tab**: Time off balance log, history table, pending approvals, company holiday calendar.
- [x] **Training Sub-Tab**: Upcoming & completed courses, Record Training modal, certificate download.
- [x] **Documents Sub-Tab**: Employee signature documents, uploaded files, Request Signature modal.
- [x] **Notes Sub-Tab**: Private HR & Manager notes log with Add Note form.
- [x] **Benefits Sub-Tab**: Health, Dental, Vision, and 401(k) benefits summary & enrollment form.
- [x] **More Sub-Tab**: Company assets tracking (Laptops, Badges, Monitors).

---

## 4. People Directory Controls & Views
- [x] **+ New Employee Button**: Multi-step onboarding wizard (Personal -> Job -> Pay -> Access).
- [x] **View Mode Toggles (List / Directory / Org Chart)**:
  - `List`: Table with clickable employee links, sorting, and action menus.
  - `Directory`: Card grid view with photo, title, department, and contact links.
  - `Org Chart`: Expandable interactive org chart tree visualization.
- [x] **Filter Bar**: `All Employees`, `Showing Active` dropdowns, employee count counter.

---

## 5. Hiring ATS Pipeline & Job Openings
- [x] **+ New Job Opening Button**: Create job opening modal (Title, Dept, Salary, Description, Hiring Lead).
- [x] **Sub-Tabs (Job Openings / Candidates / Talent Pools)**:
  - `Job Openings`: List of active/draft jobs with candidate count.
  - `Candidates`: Interactive Kanban recruitment board (Applied -> Screening -> Interview -> Offer -> Hired).
  - `Talent Pools`: Sourced talent lists & tags.
- [x] **View Careers Website**: Public career portal preview modal.
- [x] **Get Embed Code**: Embeddable HTML/JS widget snippet generator.

---

## 6. Reports Suite
- [x] **+ New Report Button**: Custom report generator wizard (Select metrics, filters, output format).
- [x] **Folder Icon Button**: Create report folder.
- [x] **Sub-Tabs (Recent / Standard / Benchmarks / Custom / Signed Documents)**:
  - `Standard Reports`: Headcount trend, Turnover, Turnover by Dept, Time Off balance report.
  - `Signed Documents`: Audit trail of signed employee disclosures.
- [x] **Favorites Cards (Headcount, Turnover, Additions, Time Off)**: One-click report runner.

---

## 7. Files & Document Vault
- [x] **Upload File Button**: File upload modal with category picker.
- [x] **New Folder Button**: Add custom folder category.
- [x] **Interactive Category Folders**: Filter files by category (Loans, Contracts, Appraisals, etc.).
- [x] **File Actions**: Select All, Sort A-Z / Date, Download File, Delete File.

---

## 8. Compensation & Pay Bands
- [x] **+ Add Pay Grades & Bands**: Pay band builder modal (Grades 1-10, Min/Mid/Max salaries).
- [x] **Import Pay Grades & Bands**: CSV/Excel import parser modal.
- [x] **Sub-Tabs (Pay Grades & Bands / Total Rewards / More)**: Total rewards statement preview.

---

## 9. Global Employment
- [x] **Region Management**: Workforce stats across Israel, US, Philippines, UK.
- [x] **Manage Agreements**: View regional legal contracts & international compliance status.
